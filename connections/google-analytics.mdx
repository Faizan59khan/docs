## Before you connect

Use a Google identity with access to the GA4 property. Know the property name and which event or key event represents your goal. A Google Ads connection does not replace the GA4 connection.

## Connect and verify

1. In the intended workspace, open **Get started > Connect accounts**.
2. Find **GA4** and choose **Connect**.
3. Complete the provider sign-in and review the permissions shown. Select an identity with access to the intended GA4 property.
4. Back in Nerve, check the connection status and use **Verify** if available.
5. Ask your assistant to list accessible GA4 properties before requesting a report.

## What to ask Nerve

Start with traffic, source/medium, channel, landing-page, geography, device, or event reports. The reviewed GA4 tool catalogue describes read-only reporting. Ask for available dimensions and metrics when you need a more specific breakdown.

```text
List the GA4 properties available through Nerve. For Example Brand,
report sessions, users, and the available lead event by source/medium
for the last 7 complete days. State the property, timezone, event name,
and missing metrics. Do not change any settings.
```

## Check scope and limits

An active Google connection is not proof that the intended property is available. Ask for the property list even if a connection summary contains no stored property IDs. Do not expect GA4 and advertising-platform conversions to match without checking their definitions, date boundaries, and attribution.

If the expected account is missing, use [connection troubleshooting](/support-and-privacy/connection-problems). For expired access, see [Check or reconnect an account](/connections/connection-status).
