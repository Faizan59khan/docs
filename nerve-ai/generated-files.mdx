When Nerve AI creates a file, look for **Files generated** in the conversation. Ask for the format and contents you need; a written answer does not necessarily include a downloadable file.

## Request a useful file

```text
Using the selected account, create a downloadable weekly report
for the last 7 complete days. Include an executive summary,
campaign table, comparison dates, currency, metric definitions,
missing data, and three recommendations. Do not change campaigns.
If you cannot create a file, tell me and provide the report in chat.
```

## Preview and save

1. Locate **Files generated** beneath the relevant output.
2. Use the preview or eye control when available.
3. For an HTML report, use **Open in new tab** or **Fullscreen** in the viewer when those options appear.
4. Choose **Download** to save your own copy.
5. Open the downloaded file and check its contents before sending it to a client.

Check that the file uses the right account, dates, currency, and result definitions. A polished layout does not establish that all source data loaded successfully. Ask the assistant about missing metrics or incomplete requests before relying on the report.

## Work with your own files

For a brief or creative file that you need to supply, use Claude or ChatGPT's file attachment feature with Nerve connected. Do not assume the built-in Nerve chat accepts uploads just because it can generate downloads.

## Keep important output

Download files you need before archiving a conversation. Treat saved reports as a snapshot of the data and analysis at generation time. For repeat reporting, use a clearly named period and verify the latest data in a new run.

If no file appears, ask whether generation succeeded and request an in-chat version while you investigate. See [Contact support](/support-and-privacy/contact-support) if a generated file cannot be opened.
