Choose how to use Nerve based on the task and where you want to work. Connecting your marketing platform is a separate step from choosing your assistant.

| Experience | Best starting point | How you select data |
| --- | --- | --- |
| **Nerve AI** | Ask a question inside Nerve | Select accounts or an advertiser group in the chat. |
| **Claude** | Work in Claude with the Nerve connector | Check the authorized connection, then name the exact account in your request. |
| **ChatGPT** | Work in ChatGPT with the Nerve plugin | Install and select the plugin, then confirm accessible accounts. |
| **Workflow** | Repeat a defined task manually or on a schedule | Configure sources and accounts in the workflow builder. |

## For a quick answer

Start a [Nerve AI chat](/nerve-ai/start-chat) and select one account. Ask a limited question, such as spend and clicks for the last seven complete days. Nerve AI replies and workflow runs use workspace credits; check [credit usage](/billing/credits) for how to review charges.

## For a brief or file-based task

Use Claude or ChatGPT when your task needs a file supplied through that assistant. For example, upload a campaign brief there and ask Nerve to compare the plan with connected account performance. File support and limits depend on the assistant you use.

## For repeatable work

A [workflow](/workflows/create-workflow) saves instructions, sources, and destinations. Review the generated steps and any email recipients before running it. Scheduling a workflow that can change campaigns is an ongoing operating decision; define its limits explicitly.

Integration coverage differs between these experiences. Check [supported integrations](/connections/supported-integrations) before choosing a surface. An external assistant's subscription is separate from your Nerve workspace plan.
