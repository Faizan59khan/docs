Nerve AI is the assistant built into the Nerve app. You can ask about connected account data without opening Claude or ChatGPT.

## Start your first conversation

1. Go to **AI Agents > Agents**.
2. Open the account picker and [select at least one account](/nerve-ai/choose-accounts).
3. Choose a starter card or type a request. The starter cards include **Campaign health check**, **Check budget pacing**, **Top performers today**, and **Where should I move budget?**
4. Send the message. While Nerve retrieves data, the chat shows progress before the answer appears.
5. Read the response and confirm that it used the intended account and reporting period.

A first message can be as specific as:

```text
For the selected Meta account, summarize campaign spend and clicks
for the last 7 complete days. Include paused campaigns where data
exists. State currency, dates, and any failed data requests.
Suggest the next questions to investigate. Do not change anything.
```

## Work with the response

Use **Copy** to reuse a message. For wide tables, scroll horizontally to inspect the remaining columns. Ask a follow-up that names the campaign or metric you want to investigate rather than assuming the assistant has answered every part of the task.

Choose **New chat** for a fresh conversation. Check its selected accounts before sending: the account choice can be remembered from previous work in the workspace.

## If a message cannot start

Check the account selection, platform connection, workspace access, and available credits. A successful response should distinguish actual retrieved results from assumptions or unavailable fields. For an empty account, ask what filters and permissions were checked before treating zero results as conclusive.

Nerve AI replies use workspace credits. Review [credits and transactions](/billing/credits) for the recorded charge.
