Use the **Chats** list in Nerve AI to return to a previous analysis. Before continuing an older conversation, check both its account scope and the dates discussed.

## Reopen a conversation

1. Go to **AI Agents > Agents**.
2. Open the **Chats** list and select the conversation you need. On a smaller screen, use the chat-history control if the list is hidden.
3. Review the recent messages and account selection.
4. Ask for a fresh retrieval if the question concerns current performance.

A previous answer describes the data available when it was produced. Reopening the chat is not a request to refresh every number.

```text
Refresh this analysis for the last 7 complete days using only the
accounts selected now. State the new dates and any differences in
account scope. Do not reuse old totals without retrieving them again.
Make no changes.
```

## Start separate work

Choose **New chat** for a different client, reporting task, or question that benefits from fresh context. Confirm its account selection: your last choice can be remembered.

## Archive a conversation

Download any reports or other files you want to keep. Then open the conversation's **Archive** action and read any confirmation before continuing. Archiving removes the chat from the main list.

Do not use Archive as a substitute for a verified data-deletion process, or assume you will be able to restore every file later. Ask [support](/support-and-privacy/contact-support) if you need retention or deletion details.

For workflow output, open the workflow's **Runs** history rather than relying on the chat list. See [Run a workflow and review results](/workflows/run-results).
